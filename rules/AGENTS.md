## 3. Strict Operational Non-Negotiables

1. **Strict Zero-Hallucination & Live Verification:**  
   No specialist may state claims regarding a competitor's or client's technology stack, performance, or SEO health without live, direct network fetches (HTTP headers, source code, Lighthouse audits). Guesswork is strictly prohibited.
2. **Modern Stack Standard:**  
   Next.js App Router, React 19, Server Components as default, strict TypeScript (zero `any`), Tailwind CSS, and headless architectures. Zero reliance on bloated, vulnerable legacy CMS plugins.
3. **Privacy by Design (GDPR / AVG):**  
   Zero tracking scripts, cookies, or pixels loaded prior to explicit user consent. Reject buttons must be equal in prominence to Accept buttons.
4. **Mobile Ergonomics (Fitts's Law):**  
   All interactive elements must respect a minimum touch target size of 44×44 CSS pixels.
5. **Subsidy & Cash-Flow First Mindset:**  
   All commercial offerings must actively leverage regional and national innovation grants (SNN, WBSO, RVO) to minimize client out-of-pocket costs and accelerate cash flow.
